\# 🛒 Ecommerce Website



A full-stack MERN ecommerce website with a customer-facing shopping application, an admin dashboard, product management, order management, authentication, coupons, and online payment integration.



\## 🚀 Features



\### 👤 Customer Features



\- User registration and login

\- User authentication

\- Browse products

\- Product details

\- Product search

\- Category-based product browsing

\- Add products to cart

\- Update cart quantities

\- Select product sizes

\- Checkout

\- Address management

\- Cash on Delivery

\- Stripe payment integration

\- Razorpay payment integration

\- Order placement

\- Order history

\- Order status tracking

\- Coupons and discount support

\- About page

\- Contact page

\- Responsive design



\### 🔐 Admin Features



\- Admin authentication

\- Admin dashboard

\- Product management

\- Add products

\- Delete products

\- Product listing

\- Customer management

\- Order management

\- Update order status

\- Order statistics

\- Revenue statistics

\- Payment statistics

\- Coupon management

\- Dashboard analytics



\### 💳 Payment Integration



This project supports:



\- Cash on Delivery

\- Stripe

\- Razorpay



Stripe webhook integration is used to update payment status after successful checkout.
